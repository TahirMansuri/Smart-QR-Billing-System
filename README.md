# 🛒 Smart QR Billing System (MiniStore)

> A lightweight, offline-first Point of Sale (POS) and billing system built with pure HTML/CSS/JS. Features integrated QR code generation, camera-based scanning, and thermal receipt printing.

## ✨ Features

- **📱 Fully Responsive:** Works flawlessly on laptops, tablets, and smartphones.
- **🔌 Offline First Architecture:** Uses browser `localStorage` as a database. No backend server or active internet connection required after the initial load.
- **🔣 QR Code Engine:** Automatically generates scannable QR labels for products.
- **📷 Built-in Scanner:** Uses device cameras to scan product QR codes and instantly add them to the billing cart.
- **🧾 Smart Billing:** Auto-calculates net prices, cart subtotals, and prints formatted thermal receipts.

## 🛠️ Technology Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript (No Frameworks)
- **QR Generation:** [QRCode.js](https://github.com/davidshimjs/qrcodejs)
- **QR Scanning:** [html5-qrcode](https://github.com/mebjas/html5-qrcode)
- **Icons:** FontAwesome
